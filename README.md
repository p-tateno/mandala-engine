# Mandala Engine for Obsidian v0.25.0

Markdownノートを中央に置き、8つの関連ノートを3×3で表示・編集する試作版です。v0.2では、メイン画面をマンダラだけにする集中モードを追加しました。

右上のオプションパレット最下部に現在のバージョンを表示します。バージョン表記をクリックすると、Mandala Engineについての小さなAbout画面が開きます。

## インストール

1. このフォルダをVault内の `.obsidian/plugins/mandala-engine/` にコピーします。
2. Obsidianを再起動します。
3. 設定 → コミュニティプラグインから「Mandala Engine」を有効にします。
4. マンダラの中心にしたいノートを開きます。
5. 左側のグリッドアイコン、またはコマンド「Open Mandala in main workspace」を実行します。

従来のサイドバー表示は、コマンド「Open Mandala in sidebar」から開けます。

### GitHub / BRATから試す

GitHubで公開したリポジトリをBRATへ登録すると、Mac・iPhone・iPadへ同じテスト版をインストールできます。

1. ObsidianのコミュニティプラグインからBRATをインストールします。
2. BRATの「Add a beta plugin」を開きます。
3. Mandala EngineのGitHubリポジトリURLを入力します。
4. 「Mandala Engine」を有効にします。

iPhone・iPadでは、セルのタップで移動、空セルのタップで編集、接続済みセルの長押しで編集します。デスクトップのセル移動・交換に使うドラッグ＆ドロップは、現時点ではMac版の操作です。

## Mandala Explorer

左側のツリーアイコン、またはコマンド「Open Mandala Explorer in sidebar」を実行すると、Obsidianの右サイドバーにMandala専用のアウトラインを表示します。

- 現在のルートから接続されたノートを、セル`1`〜`8`の順で表示（番号そのものは表示しません）
- 矢印から下位のMandalaを展開・折りたたみ
- 現在表示中のノートをハイライト
- MandalaノートをクリックするとMandala Engine内を移動
- Mandalaノートにはアイコンを付けず、通常のMarkdown参照だけを書類アイコンで区別
- 空白セルは表示せず、循環や同じノートの再帰的な重複展開を防止

左側のファイルエクスプローラーの選択状態には介入しません。通常のファイル操作はObsidianに任せ、Mandalaの現在位置と階層は右側のMandala Explorerで表示します。

## 背景画像

Vault内の画像を9セル以外の背景部分へドラッグ＆ドロップすると、そのMandalaの背景写真として設定されます。画像は移動・変更せず、実際のVault内パスをルートYAMLへ保存します。

背景写真は下位のMandalaへ継承されます。右上のオプションパレットから濃さを10〜100%で調整でき、「背景画像を解除」で元の背景色へ戻せます。

## プロパティ

プラグインが次のプロパティを自動管理します。

- `mandala_title`: セルに表示する短いタイトル
- `created`: Mandalaノートとして初期化した日付
- `mandala_role`: 独立したマンダラは`root`、空セルから生成した子ノートは`child`
- `mandala_summary`: ノートをセルに表示するときの短い説明
- `mandala_parent`: `child`を生成した親ノート
- `mandala_1`〜`mandala_8`: 周囲8セルから接続するノート
- `mandala_1_type`〜`mandala_8_type`: マンダラ生成ノートは`child`、既存ファイルの参照は`reference`
- `mandala_background_color`: 階層全体で使うマンダラ背景色（ルートのみ）
- `mandala_gray_cell_color`: 奇数・偶数パターンのグレーセル色（ルートのみ）
- `mandala_background_image`: 背景へ表示するVault内画像（ルートのみ・子へ継承）
- `mandala_background_image_opacity`: 背景画像の濃さ（0.1〜1、初期値0.3）
- `categories`: マンダラに表示したノートへリスト項目`[[mandala]]`を追加

MandalaノートはVault直下の`Mandala`フォルダへ自動収納します。サブフォルダは作りません。

ファイル名は`mandala_title`と同じ名前になります。

```text
Mandala/希依ちゃん.md
```

同じタイトルのファイルが既に存在する場合は、上書きせず`希依ちゃん 2.md`、`希依ちゃん 3.md`のように連番を追加します。

通常の新規ノートを初めてマンダラとして開く場合は、現在のファイル名を`mandala_title`として設定し、そのまま`Mandala`フォルダへ移動します。
ルートノートの中央セルは、クリックするとタイトルと要約文を直接編集できます。
ルート・子のどちらも、後からタイトルを変更するとファイル名を更新して`Mandala`フォルダへ収納します。同名が存在する場合は連番を追加します。

## v0.2の機能

- メイン画面にマンダラだけを表示する集中モード
- 集中モードでは、セルを移動してもマンダラ画面を維持
- サイドバー表示も引き続き利用可能
- 通常表示と同じ見た目のまま、タイトルと要約文をセル内で直接編集
- 一度に編集するのは操作した1セルだけ
- 通常の`reference`セルだけ右下へ書類アイコンを表示し、Markdownファイルを新しいタブで直接開く（Mandalaルートはアイコンなし）
- 接続済みセルを`Option＋クリック`してMarkdownファイルを直接開く
- Mandalaタブ名に、現在のセンタータイトルを`Mandala - タイトル`形式で表示
- 空セルをクリックして新しい接続を入力（「＋」は表示しません）
- ファイルエクスプローラーからMarkdownファイルを空セルへドラッグ＆ドロップして接続
- 既存ファイルのドラッグ＆ドロップは参照だけを追加し、`mandala_role`と`mandala_parent`を変更しない
- 空セルから生成した接続は`child`、ドラッグ＆ドロップした接続は`reference`としてセル側に記録
- セルをドラッグしたまま接続済みセル上で1.8秒保持するとリングが現れ、さらに0.9秒後（合計2.7秒）にそのセルをセンターにしたMandalaへ移動
- ページ間ドラッグ中にセンターセルで保持すると、一つ上の階層へ戻って移動先を選択
- 親との接続が分かるセンターセルは、センター自身をドラッグして下位構造ごと別の位置へ移動
- 自分自身や自分から辿れる下位階層へのドロップを拒否し、Mandala接続の循環を防止
- 外観は「自動・ライト・ダーク」から選択し、ルートYAMLの`mandala_theme`から子階層全体へ継承
- 自動外観はObsidianのライト／ダークへ追従し、プラグイン設定でデフォルト外観を指定
- Mandala画面で`Command＋Z`（Windowsは`Ctrl＋Z`）、またはコマンドパレットから直前のセル移動／交換を取り消し（最大20手）
- 集中モードで通過したノートを記録するpowderful track
- track内のノート名または中央セルから、通ってきた経路へ戻る
- 子ノートから直接開いた場合も、`mandala_parent`をルートまでたどってtrackを復元
- 周囲の接続済みセルをドラッグして、別の周囲セルと配置を交換
- 空セルへドロップした場合は、その位置へ接続を移動
- 接続解除後、接続先ファイルを残すかゴミ箱へ移動するか確認
- 設定から「すべて白」「1・3・5・7を薄いグレー」「2・4・6・8を薄いグレー」の配色を選択
- 各マンダラの`mandala_color_mode`を、右上のオプションパレットから変更
- `inherit`の子ノートは`mandala_parent`をたどって親の配色を継承

## 設定

Obsidianの設定 → コミュニティプラグイン → Mandala Engineから、デフォルトの周囲セル配色を選択できます。各ノートが`inherit`で、親にも明示設定がない場合に使われます。

「MandalaノートをMandala Engineで自動的に開く」をオンにすると、`Mandala`フォルダ内の`mandala_role: root`または`child`のノートを開いたとき、同じタブを自動的にMandala表示へ切り替えます。従来形式との互換性のため、フォルダ外の既存rootノートも対象です。Mandala Engine内の書類アイコンまたは`Option＋クリック`でMarkdownを直接開く操作は、自動切り替えを一度だけ回避します。

通常クリック、Basesからの表示、階層移動、保存されたタブの復元では、Mandala用YAMLを追加しません。通常のMarkdownを新しくMandala化するのは、コマンド「Open Mandala in main workspace」を明示的に実行したときだけです。復元されたMandalaタブのルートから`mandala_role: root`が削除されている場合は、YAMLを復活させずMarkdown表示へ戻します。

Markdownノート上で「Open Mandala in main workspace」を実行すると、新しいタブを増やさず、現在のMarkdownタブをそのままMandala表示へ切り替えます。

画面右上の薄い調整アイコンへカーソルを合わせるかタップすると、ノートごとの配色設定が表示されます。

背景色とグレーセル色はルートノートのYAMLだけに保存され、すべての子マンダラへ引き継がれます。子階層で色を選んだ場合も、保存先はルートノートです。白いセルと奇数・偶数の配置パターンは維持されます。

空セルとルート中央セルはクリック、接続済みセルはShift＋クリック、またはセルにカーソルを置いて`E`キーで編集できます。iPhoneではセルの長押しで編集します。`⌘/Ctrl＋Enter`で保存、`Esc`または背景クリックで終了します。未保存の変更がある場合は、保存・破棄・編集継続を選べます。

- 現在のノートを中央に表示
- 8方向へ既存ノートを接続
- 新しいノートを作成して接続
- 接続セルをクリックしてノート間を移動
- 中央セルから親ノートへ戻る
- 各ノートの短い説明をセルに表示
- ダークモードでも、マンダラは薄いグレーの背景と白いセルで表示
- 新しく作るMandalaノートは`Mandala`フォルダへ保存
